# 🔥 Kiln

**Describe it once. We'll forge the plan.**

A landing page where you describe what you want to build, pick which integrations should exist
around it, and get back a real, structured build plan generated by Claude — with the selected
integrations actually injected into the model's system prompt, not just displayed as UI decoration.

Built for the Stunning "Full-Stack Vibe Coder" take-home task.

## What this actually does

1. You type a one-line idea into the prompt box — e.g. *"Build a subscription dashboard that
   shows analytics, manages customers, and sends weekly email reports."*
2. You toggle any of five dummy integrations: **Stripe, Shopify, Gmail, Slack, Google Sheets**.
   These don't connect to real accounts — they exist purely as context the model should assume is
   available.
3. You hit **Forge the plan**. The frontend sends `{ prompt, integrations }` to `POST /api/generate`.
4. The API route builds a **system prompt that changes based on exactly which integrations you
   picked** (each one has a real one-line description of what it means for the build — not just its
   name), and sends it to Claude along with your prompt.
5. Claude replies with structured JSON: an overview, a feature list, a tech stack, and an ordered
   build plan. The UI renders it as a tabbed panel.
6. A live preview panel on the page mirrors the **actual** system prompt as you toggle integrations
   — so you can literally watch the prompt change before you even submit. This is the real string
   sent to the model, not a mockup of it.

## Quickstart

Requires **Node 18.17+**.

```bash
# 1. Install dependencies
npm install

# 2. Set up your environment file
cp .env.example .env.local
# then open .env.local and paste your real key in place of sk-ant-...

# 3. Run it
npm run dev
```

Open **http://localhost:3000**. That's it.

> The app boots and the UI works fully even without a key — you'll only see an error once you
> click "Forge the plan," and it'll tell you clearly what's missing.

## Environment variables

`.env.example` is a **template**, not a real key — copy it to `.env.local` and fill in your own.
`.env.local` is git-ignored on purpose so you never commit a real secret.

| Variable | Required | Description |
|---|---|---|
| `ANTHROPIC_API_KEY` | ✅ Yes | Your personal key from [console.anthropic.com](https://console.anthropic.com/settings/keys). Used server-side only — never sent to the browser. |
| `ANTHROPIC_MODEL` | ❌ No | Overrides the model id. Defaults to `claude-sonnet-5`. |

Don't have a key yet? Sign up at console.anthropic.com, verify your phone number, and go to
**Settings → API Keys → Create Key**. New accounts get a small free credit, which is plenty to run
this project and record a demo.

## How the integration → system prompt flow works

This is the actual mechanic the task is testing, so here's the real flow, not the marketing version:

```ts
// lib/integrations.ts — every integration has real context, not just a label
{
  id: "stripe",
  name: "Stripe",
  context: "Stripe is available for payments, subscriptions, invoicing, and billing.
             Assume the product can charge cards, manage plans, and track revenue events."
}
```

```ts
// app/api/generate/route.ts — only the SELECTED integrations get added to the prompt
if (selected.length > 0) {
  base.push(
    "The user has selected the following integrations for this build...",
    ...selected.map((i) => `- ${i.name}: ${i.context}`)
  );
}
```

So toggling Stripe **on** and Slack **off** genuinely produces a different system prompt, and
therefore a different plan — not just a different-looking checkbox.

## Tech stack

- **Next.js 14** (App Router, TypeScript) — one project, frontend and backend together
- **Tailwind CSS** — all styling, custom charcoal/ember token system
- **@anthropic-ai/sdk** — server-side only, calls Claude from the API route

## Design notes

- **Server-side validation, not just client-side.** Empty prompts, prompts over 1200 characters,
  and unknown integration ids are all rejected/filtered inside the API route itself.
- **A missing API key fails with a clear message**, not a crash or a silent hang.
- **The model's JSON is parsed defensively** — stray markdown fences or extra prose around the
  JSON won't break the UI; if parsing genuinely fails, you get the raw text back with a 502 instead
  of a blank screen.
- **Accessible by default** — visible focus rings, `aria-pressed` on toggles, `prefers-reduced-motion`
  respected globally.

See [`DECISIONS.md`](./DECISIONS.md) for the full "shipping tomorrow" write-up, including the
biggest production risk (spoiler: an unauthenticated route calling a paid API has no rate limit yet).

## Troubleshooting

| Problem | Fix |
|---|---|
| `Server is missing ANTHROPIC_API_KEY` | You haven't created `.env.local`, or forgot to restart `npm run dev` after adding it. |
| `402` / billing error from Anthropic | Your free trial credit ran out — add a payment method in the Anthropic Console under Billing. |
| Plan panel shows a parsing error | Rare — the model didn't return clean JSON. Just click "Forge the plan" again. |
| Port 3000 already in use | `npm run dev -- -p 3001` (or kill whatever's on 3000). |
